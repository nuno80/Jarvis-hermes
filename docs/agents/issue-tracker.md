# Issue tracker

GitHub: https://github.com/nuno80/Jarvis-hermes/issues
PRs as a request surface: off.

Use gh CLI or the authenticated GitHub connector. Each approved task is one issue.
Task keys JARVIS-01..JARVIS-30 are stable planning IDs, not GitHub issue numbers.
Resolve each dependency through the roadmap and actual issue URL.
The issue's Blocked by section is authoritative. Current connector lacks native blocking-edge operations; textual issue references are used.
Label ready-for-agent means reviewed ticket content; only work tickets whose blockers are complete.
Do not close an issue merely because documentation or a scaffold exists. Attach acceptance evidence.
Do not modify or close a parent issue as a side effect of ticket publication.
