# Domain glossary

- Jarvis: the single assistant experienced by the owner.
- Hermes: runtime owning Telegram sessions and provider integrations.
- MCP tool: a typed callable capability exposed to the runtime.
- Job: a persisted user request with progress and terminal outcome.
- Action: a specific tool effect within a job.
- Approval: owner consent bound to one action, target and parameter digest.
- Device: a registered execution target; first target is Windows with Debian WSL.
- Checkpoint: recoverable prior state of resources modified by a job.
- Vault: the separately managed private Obsidian repository jarvis-vault.
- Explicit preference: an owner-authored value, higher priority than learned inference.
- Offer: a provider-sourced travel result with price, coverage and observed timestamp.
- Unknown outcome: an external effect may have happened; reconcile before retrying.
- V1 Core: useful PC/dev/memory milestone; not completion of the entire V1.
